# D1-05 — Implement RTS camera controls and bounds

[Back to EPIC-01](../epics/EPIC-01-world.md) · [Backlog index](../../BACKLOG.md)

**Outcome:** The orthographic camera pans and zooms like an RTS.

**Owns:** `src/game/camera/`.

**Acceptance:** layout-aware ZQSD and arrow-key pan work; two-finger trackpad scrolling pans and pinching zooms; zoom is clamped; focus remains inside map bounds; controls ignore typing in UI fields; keyboard camera behavior is delta-time based.

**Verify:** manual input checklist at two viewport sizes.
