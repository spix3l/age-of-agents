# D8-13 — Pause a match and save it for later

[Back to EPIC-08](../epics/EPIC-08-depth.md) · [Backlog index](../../BACKLOG.md)

**Outcome:** A match can be put down and picked up again. Requested by a player: "be able to pause the game", "be able to save the game for later".

**Owns:** `src/game/save/SaveGame.ts`, `src/game/save/saveStorage.ts`, `MatchSimulation.restoreState`, `src/ui/menus/PauseMenu.tsx`, the pause and save state in `src/ui/store.ts`, CONTINUE in `src/ui/menus/MainMenu.tsx`.

**Acceptance:** `P` holds the match from anywhere and `Esc` or RESUME releases it; the overlay covers the viewport, so a held match cannot be played through; pausing is refused on the menu and after a result; SAVE GAME writes the running match to one local slot and says whether it worked; CONTINUE appears on the main menu whenever a slot exists and rebuilds that match — colony, economy, kill tally, generation, clock, and production queues — into the mode and difficulty it was saved in; a finished match clears the slot; a corrupt, truncated, or older save is refused rather than trusted.

**Verify:** `SaveGame.test.ts` round-trips a match through JSON, including a half-built structure and a queued Worker, proves id counters cannot collide after a load, and rejects malformed saves; `PauseMenu.test.tsx` covers the hold, the refusals, the save note, and that no pause survives into a new match.

## Outcome

A save is a description of the world, not a snapshot of the running simulation: entities, health, stock, progress, and the match-wide totals. Everything a system re-derives on its next tick — paths, gather and build orders, target locks, the opponent's plan, explored ground — is left out on purpose, so a load cannot resurrect a half-finished order into a state no system would ever have produced. `savedScenario` rebuilds the world as a fixture and `MatchSimulation.restoreState` applies the rest.

Decision: one slot, overwritten. This is a "come back to it" save, not a campaign of files.

Decision: builder assignments are dropped and re-found. `ConstructionSystem.adoptOrphanedSites` already hands an unclaimed foundation to the nearest free Worker, which is exactly the behaviour a resumed half-built structure wants.

Decision: id counters travel in the save. Without them a restored match re-mints ids its own entities already hold, and the registry throws on the duplicate.

Known limit: fog of war is not saved. A resumed colony re-reveals what it can see and re-explores the rest.
