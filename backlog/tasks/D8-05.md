# D8-05 — Make match results shareable

[Back to EPIC-08](../epics/EPIC-08-depth.md) · [Backlog index](../../BACKLOG.md)

**Outcome:** A player can show someone else how the match went.

**Owns:** `src/ui/menus/EndScreen.tsx` and a share module.

**Acceptance:** the end screen offers a share action carrying result, duration, difficulty, seed, all three resources, Agents and structures, and final Generation; it produces both a copyable text summary and a downloadable image card; sharing works offline with no backend, no third-party request, and no telemetry; the seed is included so a match can be replayed; failure to copy or download degrades visibly rather than silently.

**Verify:** summary-formatting tests and a browser check that the copy and download paths fire.
