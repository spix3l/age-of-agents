# D4-03 — Implement Attack command and combat state machine

[Back to EPIC-04](../epics/EPIC-04-war.md) · [Backlog index](../../BACKLOG.md)

**Outcome:** Strikers acquire, pursue, attack, cooldown, and retarget enemies.

**Owns:** `src/game/systems/CombatSystem.ts`, `AttackCommand.ts`, combat behavior components.

**Acceptance:** right-click hostile attacks; units path into range; cooldown uses simulation time; invalid/dead targets cause bounded nearby retargeting; attack-move is not required; buildings can be targeted; no target acquisition occurs every render frame.

**Verify:** deterministic duel, group fight, and destroyed-target tests.

## Decisions

`CombatSystem` runs acquire → pursue → attack → cooldown → retarget. Acquisition is throttled to 5 Hz (`COMBAT.acquisitionInterval`) and only idle auto-acquiring units search; attack-move was not implemented. `AttackCommand` is the shared player/AI boundary and rejects friendly targets.
