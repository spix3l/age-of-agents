# D8-03 — Seed map variation and enrich resources

[Back to EPIC-08](../epics/EPIC-08-depth.md) · [Backlog index](../../BACKLOG.md)

**Outcome:** A new match is a new map, so map knowledge stops substituting for strategy.

**Owns:** `src/game/world/map.ts`, `src/game/scenarios/economy.ts`, `src/data/resources.ts`.

**Acceptance:** terrain and resource layout are generated from the match seed and differ visibly between seeds; both factions stay strictly mirrored in composition, distance, and reachability so no seed is unfair; every start has reachable Matter, Energy, and Data; the interior is contested and expansions are worth taking; the map carries materially more total resource than the handcrafted one so armies are not capped near 20 units; no seed can produce an unreachable start, an unharvestable node, or a blocked Core.

**Verify:** a generator property suite over many seeds asserting mirroring, reachability, and resource budget, plus re-measured soaks.
