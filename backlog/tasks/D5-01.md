# D5-01 — Create AI controller, utility states, and command adapter

[Back to EPIC-05](../epics/EPIC-05-opponent.md) · [Backlog index](../../BACKLOG.md)

**Outcome:** A deterministic low-frequency AI chooses strategic states and uses normal game commands.

**Owns:** `src/game/ai/AIController.ts`, `AIStrategy.ts`, AI command adapter.

**Acceptance:** states include EXPAND_ECONOMY, TECH placeholder, BUILD_ARMY, SCOUT, DEFEND, ATTACK, RECOVER; decisions run at 2–4 Hz; fixed seeds are reproducible; no direct resource/entity mutation bypasses commands.

**Verify:** transition tests with synthetic snapshots.

## Decisions

`AIController` runs strategy at `AI.decisionsPerSecond` (3 Hz), never per frame. `AIStrategy.decideState` is a pure utility function over an `AISnapshot`, so seeds reproduce exactly. `AIContext` splits a read-only `AIView` from an `AICommands` adapter that exposes only the same commands a player uses — the AI cannot write ledgers or entities directly. TECH is declared and scored but deliberately stays at zero until D6-02 ships Generations.
