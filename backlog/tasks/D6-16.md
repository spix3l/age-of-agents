# D6-16 — Give every structure real Generation upgrades

[Back to EPIC-06](../epics/EPIC-06-evolution.md) · [Backlog index](../../BACKLOG.md)

**Outcome:** Evolving a Generation visibly rebuilds the colony instead of adding a badge to each roof.

**Owns:** `src/game/rendering/models/buildings.ts` generation tiers and the growth animation in `WorldScene`.

**Acceptance:** every building kind gains distinct Generation II and Generation III geometry — storeys, armour, dishes, crowns, cannons — that changes its silhouette at default zoom; new structure casts and receives shadows; each structure that gains mass pops in with a burst so the evolution is felt colony-wide; upgrades stay purely presentational with no stat or balance change.

**Verify:** `src/game/rendering/models/models.test.ts` asserts both tiers exist per kind, plus a default-camera visual pass at each Generation.
